# 朝霞市版 5374(ゴミナシ).jp

## 「いつ、どのゴミが収集されているのか？」

お住まいの地域を選ぶだけで、次のゴミ収集日がすぐにわかるWebアプリです。
お引っ越しされた方や、分別に迷ったときにお使いください。

[Code for Kanazawa](http://codeforkanazawa.org/) が開発した [5374.jp](https://github.com/codeforkanazawa-org/5374) を朝霞市向けにローカライズしています。

## 使い方

[HOWTOUSE.md](HOWTOUSE.md) をご覧ください。

## ローカライズについて

各地域へのローカライズについては [LOCALIZE.md](LOCALIZE.md) を参照してください。
